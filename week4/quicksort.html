Cálculo de complejidad por sustitución

Caso balanceado

Cuando el pivote divide el arreglo en dos partes aproximadamente iguales:

Recurrencia:
T(n) = 2T(n/2) + cn
Primera sustitución:
T(n) = 2[2T(n/4) + c(n/2)] + cn
T(n) = 4T(n/4) + 2cn
Segunda sustitución:
T(n) = 4[2T(n/8) + c(n/4)] + 2cn
T(n) = 8T(n/8) + 3cn
Después de k sustituciones:
T(n) = 2kT(n/2k) + kcn
Caso base:
n/2k = 1
2k = n
k = log2(n)
Resultado:
T(n) = nT(1) + cn log2(n)
T(n) = O(n log n)

Peor caso

Si el pivote siempre queda en un extremo, por ejemplo al elegir el primero en un arreglo ya ordenado:

Recurrencia:
T(n) = T(n - 1) + cn
Sustituyendo:
T(n) = T(n - 2) + c(n - 1) + cn
T(n) = T(n - 3) + c(n - 2) + c(n - 1) + cn
Hasta el caso base:
T(n) = T(1) + c(2 + 3 + ... + n)
2 + 3 + ... + n = n(n + 1)/2 - 1
Resultado:
T(n) = O(n²)
En este simulador se usa el primer elemento como pivote. Por eso un arreglo ya ordenado puede producir el peor caso.
